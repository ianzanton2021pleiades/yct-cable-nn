# V2 修改记录

## 1. S11 与距离响应严格一致

### V1 根因

V1 在 IFFT 后直接修改脉冲和阶跃曲线，包括：

- 分布式受潮下沉；
- 缺陷后曲线恢复；
- 长缺陷脉冲限幅；
- 健康 Field 末端补峰。

这使导出的 S11 无法重构导出的距离响应。

### V2 修改

- 删除全部距离域后处理函数；
- 所有缺陷、夹具、模板统计和末端补偿均在 S11 域完成；
- 每个频带只调用一次共享 IFFT；
- `core/__init__.py` 改为薄重导出，删除第二份 IFFT 实现，避免未来分叉；
- CSV 使用 `.17g`，YAML 保留完整 `epsr`；
- 增加逐点完全一致的自动测试。

## 2. 首端振荡与远端高频振铃分离

### V1 根因

- RG58 夹具由少量延迟 delta 反射组成，产生稀疏孤立峰；
- 全局非线性色散相位作用于整个 S11，使每个缺陷和末端都被同样展宽；
- 接头和终端使用近似零相位频率包络，容易在事件两侧形成对称振铃；
- Field 长缺陷的内部离散段边界曾被误当成接头。

### V2 修改

- RG58 首端采用局部时间纹理反演到 S11，形成高频、密集、随距离衰减的首端簇；
- Field 首端采用低 Q 因果模态和低通夹具回波；
- 全局相位色散被删除，改成每段 RLGC/Debye 传播色散；
- 接头和末端均使用因果最小相位核；
- 物理接头从电缆模型分段边界中独立抽样，并避开缺陷区域；
- 长缺陷参数边缘改为平滑过渡。

## 3. 开路末端阶跃可见性

### V1 根因

Field 的“开路”负载仅约 55–120 Ω，接近匹配，不可能稳定产生强开路阶跃；长电缆的高频损耗又进一步削弱末端。

### V2 修改

- Field open：450–4500 Ω（短电缆 900–9000 Ω）；
- weak_open：110–420 Ω；
- short：0.4–12 Ω；
- RG58 finite_open：650–6500 Ω；
- 当物理终端响应仍低于测量可见阈值时，在 S11 域加入因果低通终端核；
- 老化/受潮引起的有效电气长度用于终端相位定位。

## 4. 实测模板不再复制未知缺陷

### V1 根因

V1 将实测模板的复数快速残差和相位趋势直接混入合成 S11。模板中的未知接头、故障、校准残留会成为没有标签的峰，并使相同参数因随机模板而产生完全不同的空间事件。

### V2 修改

- 模板只提供平滑幅值包络、残差功率统计和频带能量尺度；
- 独立生成新的相关复噪声；
- 不迁移模板相位；
- 校正模板不再直接叠加复波形；
- 增加模板质量评分，拒绝点数不足、截幅、异常平坦或频谱病态的文件；
- 模板按目标电缆长度进行预筛选和加权，避免 100 m 与 2400 m 频带统计互换；
- 加入“改变模板反射延迟不应改变输出事件位置”的测试；
- GUI 增加固定随机种子、模板开关和实测目录输入，便于同参数可复现实验。

## 5. 受潮与老化物理化

- `SegmentParams` 新增 `tan_delta_100mhz`、`debye_delta_epsr`、`debye_corner_hz`、`debye_exponent`；
- 分布电导由介质损耗角进入 RLGC；
- Debye 型频散用于模拟介电常数随频率变化；
- 受潮同时提高电容/介电常数、漏导/介损和传播衰减；
- 长区段缺陷的阶跃下沉、波速降低和后方衰减均由 S11 自然产生。

## 6. 数据加载器修复

- 兼容 `_1GHz.csv`、`_200MHz.csv` 和 manifest 路径；
- 默认标签网格改为 2500 m / 0.25 m / 10000 点；
- 输入始终由 CSV S11 重算；
- 数据增强的距离平移同步作用于标签；
- 加入输入/标签网格一致性检查。

## 7. 其他修复

- 递归发现实测 CSV，兼容多层 ZIP 解压目录；
- 中文文件名乱码时，利用文件大小辅助识别校正数据；
- 修正当前频率栅格下 1 GHz 与 200 MHz 无模糊距离的说明；
- 删除不可达旧代码和重复距离域修饰逻辑。
