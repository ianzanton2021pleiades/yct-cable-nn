辅助事实：
- 参数 ×17.9（21万→430万）现场命中不动 → **容量不是瓶颈，架构搜索已证伪**。
- train/val gap 57–321×但 test F1 只 +0.016 → **val 有地板，"过拟合"实为合成域饱和 + 现场域真空**。
- 现场监督 6万:1（3.9M 参数 vs 65条曲线）；现场域有效训练 ≤6 epoch。
- 操作曲线无拐点：阈值 0.5→0.3，hit 0.342→0.595、候选 2.98→10.67——**凡不给候选数的提升都是口径操纵**。
- 213 条现场曲线被 12 个版本反复选型 → 测试集已是训练反馈信号。
- 交付断链：ai_libraries 为空、GUI 按钮永久禁用，12轮产物从未部署。

## 二、模型侧根因（代码级定位）

1. **输入表征缺陷**：8/12 通道中 3 个不携带空间信息（2 个逐样本常数+1 个全样本相同斜坡）；固定 0–3250m 网格不按长度裁剪（74m 电缆信息挤在前 2.3%）；400×幅度增强被逐样本 RMS 归一化完全抵消；远端 1e-4 量级特征在输入中不可分辨（1500m+ hit 0.196 的直接机理）。
2. **损失 bug**：unknown 通道被 `stack_targets` 置零 → topk_unknown_sparsity 恒 0 从未生效；事件项占损失 92%（正样本 0.569+背景 0.092），背景约 8000 点放大约 4000×；focal 地板：损失对位置误差不敏感、对概率饱和敏感（损失地形：位置对 0.394 vs 位置对但概率饱和 0.827 vs 训练平台 0.78）。
3. **多因素叠加无法归因**：PINN2 的"+0.170"被审计证伪为检查点错配（v1 微调实际 0.4595）；12 轮每轮 3 小时寿命，无一轮做"生成器×模型×划分"对照矩阵。
4. **评估污染**：selection_score 与 field_macro_hit20 逐行相等；finalize_delivery 直接读 test；阈值在 test 上扫。

## 三、HumanDoc 论文可采纳方法（按用途分组）

**标签/损失**
- 稀疏定位标注 → 逐点最大叠加的**高斯软标签**（σ=数采样点），BCE 损失（Duarte 2026）。
- 反射点标注用"上升沿 50% 准则"而非峰值（抗色散峰移）。
- 分段概率向量（等分 N 段 0/1）+可选回归头（起止+严重度）比单点回归稳健（Wu 2021）。
- PU 学习：现场"只标正例"场景，非负风险估计（对风险 max(0,·) 裁剪）防负经验风险过拟合（Kiryo 2017）。
- 难样本：OHEM top-k（历史 PINN2 已验证：背景误报 −25%）。

**结构**
- 1D U-Net/编码-解码做"波形→逐位置输出"主干的直接先例（Wang 2025 序列式；stride-1 保持时间对齐）。
- 检测式头（anchor/峰值+置信度）定位精度高于序列式（Wang 2023、Duarte 2026）→ **双头组合：逐位置分割头 + 全局末端回归头**。
- 帧归一化层（学习每帧缩放）防弱反射被强反射淹没（Chang 2023 LSTM-VAE 的启发）。
- 传播衰减补偿后再输入，使幅值反映严重度而非距离（Liu 2026：幅值比 0.803→1.025）。
- 级联任务分解：检测→分类→按类回归（Goudjil 2026）。
- TCN 膨胀因果卷积做长感受野补充（Goudjil 2026、Duarte 2026）。

**输入表示**
- 3 通道起步：Re、Im、归一化坐标轴，按训练集统计标准化（IsmailPence 2026）。
- 中文技术报告（宽频阻抗谱）：**脉冲响应+阶跃响应+阻抗曲线三图联用是现场判读标准**——输入通道应同时含脉冲（实/虚或幅值符号）与阶跃。
- 距离轴按本条电缆估计长度归一化（历史报告+Qoder-Flash）。
- 对数压缩通道让远端 1e-4 特征可分辨（历史报告第4步）。

**训练策略**
- 增广套件（仅训练集、每次随机2种）：低频漂移/偏置、带内±3dB线性相位均衡、整数平移、0.9–1.1伸缩、AWGN 6–20dB；**禁止**非线性相位滤波与插入合成回波（Duarte 2026）。
- AdamW + 5% warmup + cosine、梯度裁剪、不早停取 val 最优（Duarte 2026：200 epoch 靠大增广防过拟合——对应用户"85–100轮不过拟合"的诉求）。
- 域适应最低成本：冻结骨干微调头（Wu 2021 负载域迁移）。
- "合成→CST→实物"三级验证量化 sim-to-real（IsmailPence 2026：40万纯合成样本+三级验证）。

**评估**
- F1(δ) 一对一匹配（同容差取最高置信度），同时报漏检/误报；分类报 per-class+混淆矩阵（Duarte、Goudjil）。
- 固定候选预算工作点比较；precision 常规输出；末端报全分母覆盖率（历史 CodeX §7.4）。
- 分距离桶报告 + 组级 bootstrap CI（现场 40 个点上 CI ±15%）。

## 四、模型升级决定（本轮执行基线）

用户已确认的执行参数：
1. **任务/标签**：角色+机理双头。角色头4类（背景/接头/末端/缺陷），机理头（正常接头/浸水受潮局部/浸水弥散/老化/低阻短路/屏蔽串联损伤/气隙/开路末端/短路末端/负载末端）。
2. **现场数据**：合成预训练 → 现场微调（约80%有标注现场数据），封存约20%+受控实验做盲测。
3. **数据集**：约3万样本/600+模板，模板级留出 ≥10%。
4. **频带**：1GHz标准50000点 80% + 快速10000点 15% + 200MHz带 5%。

模型设计（基础版 → 高级版路线）：
- **基础版 U-Net 1D**：输入固定空间网格 0.25m×10240 点（覆盖 0–2560m，≤2.5km 短电缆聚焦），通道 = 脉冲实部/虚部/阶跃/对数幅值/归一化距离轴（5通道）；stride-1 stem + 下采样 U-Net（5级池化→320）；双分割头（角色4×L、机理10×L）+ 末端位置全局回归头。
- 损失：BCE on 高斯软标签（σ(x)=max(3m,0.02x)）+ OHEM 背景 top-128 + unknown mask（可观测性）；末端头 SmoothL1。
- 训练：AdamW、warmup 5%+cosine、梯度裁剪、batch 按显存（CMP 90HX 10G）、85–100 epoch（>50 epoch 的正式训练写成脚本交用户执行，含断点续训）。
- 增广：AWGN、增益纹波、时移、伸缩、衰减抖动（Duarte 套件，仅训练集）。
- **高级版**（基础版达标后才做）：PINN2 式多尺度对比度前端、TCN/注意力块、末端条件物理后处理、集成。
- 评估协议（先于训练冻结）：固定候选预算（3.0/条）工作点、F1@max(5m,0.02d) 与 F1@20m 双口径、precision/recall 常规输出、分距离桶、末端全分母覆盖、合成模板留出 val + 封存现场盲测集双报告、组级 bootstrap CI。

## 五、不许再走的路（模型侧）

- 换架构/加容量解决域差（×17.9 参数不动；Transformer 两次不如 U-Net；Mamba 未做对照即弃）。
- 延长训练量补救（50→150轮 gap 0.098→0.329，现场反而降）。
- 注入式增广作为最终解（注入域 0.42–0.46、原始现场不动；高斯核不是接头物理）。
- mixup 特征域相加 + 标签取 max（不是电缆前向）。
- 纯合成指标当验收（合成 val/test 差 0.005，与现场 hit 完全脱钩）。
- 阈值在 test 上扫、selection 读 test 键、迭代反复吃同一批现场曲线。
