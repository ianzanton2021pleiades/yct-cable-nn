### dataset.py v3 细节

- **valid_len 一律读 `meta["valid_len"]`**（合成与现场统一）；DG_V4 旧 meta 无此键时回退数组长度（仅向后兼容评估）。
- **逐像素正例权重图** `w(d) = max(weight of 覆盖事件)`，默认 1.0；BCE 正项乘该图（role 与 mech 头都乘）。
- **z0 目标**：合成样本载 `z0_dev`（补零到 GRID，`z0_w=1` 于 valid 区）；现场样本 z0 目标=全 NaN、`z0_w=0`（loss 按布尔索引取像素，NaN 不参与）。
- **现场负例不硬压**（domain 由数据目录决定，DG_V5 的 field-profile 合成样本仍按 synth 处理）：
  - role 头通道1(接头)/3(缺陷)：`role_cm` 只在正例支撑区为 1，负例像素全 0 → 不参与 top-256 背景挖掘（其负例损失恒 0）；通道2(末端)与背景(通道0)照常全负例监督；
  - mech 头：`mech_cm = (mech_t>0)`，全部负例像素为 0；`mechanism=null` 的事件不写 mech 目标；
  - 合成样本 `role_cm/mech_cm` 全 1，一切照旧。
- **--extra-log**（默认关）：ch4 = sign·log1p(2000·|impulse|)，cin=5。
- 增广保持现状（仅训练集）；新增 `MixedBatchSampler`（field 全量 + 每轮动态抽 `replay_frac`=25% 合成回放，按长度分桶、批内自然混合）与 batch 键 `z0/z0_w/w_map/role_cm/mech_cm/domain/l_full/valid_len`。

### train.py v3 细节

- **pretrain**（默认 70ep，lr 2e-3，AdamW+warmup+cosine，bf16）：只用合成 train split；选型 = synth_val loss；每轮额外跑 field_val decode（49相）打印 `field_f1_20` 监控列（不选型）。
- **mixed**（默认 35ep，lr 2e-4）：载 `--init` 预训练 best.pt；数据 = field_train 全部 + 每轮 ~25% 合成回放；选型 = field_val F1@20（协议 v2 9.5）；每轮打印 `synth_val_loss` 防遗忘监控。
- **损失** = role + mech_w·mech + 0.3·term + 0.3·z0（SmoothL1，仅合成 z0 有效像素）；验证 loss 保持规范无权公式（pos_weight=1、hard_k=256、mech_w=1），域掩码照用。
- history.json 每轮记录：`train_{loss,role,mech,term,z0}` + `val_*` + `synth_val_loss` + `field_f1_20` + `field_val_loss` + lr + time_s。
- resume 机制保留（`--resume` 读 `<out>/last.pt`，epoch/opt/history/best 全恢复）；tqdm 进度条（训练 loader）。
- 共享解码逻辑 `decode_f1` 改从 evaluate.py 导入（含末端配额与 valid 区限制），保证训练监控与正式评估同口径。

### evaluate.py v3 细节

- **末端通道配额=1**：channel2 只取最高局部极大参与候选池；候选限制在 valid 区内；其余照旧（预算3.0、阈值0.5、NMS 25m、同角色一对一）。
- **末端双口径**：主 = 响应锚定 `anchor_m`（`terminal_anchor`，达标口径）；并行 = txt 全长 `terminal_full_length_m`（meta 缺则该条跳过，`terminal_full`），各报 denominator / output_rate / hit50 / mae。
- **规则法基线**（同文件）：|impulse| 在 valid 区局部极大 → 按幅值排序 → NMS 25m → 取 budget 个；其中落在 [0.6,1.35]×L_full 窗口的最强峰指派为末端候选（REF GUI 末端搜索逻辑），其余峰朴素指派为"接头"。
- **双匹配口径**：role-matched（NN 现行）与 role-agnostic（候选↔任意标注事件），NN 与基线都输出两套；每套含 adaptive 容差与 F1@20 两套计数 + 250m 分桶表（role-matched@20）。
- **工作点**：主 3.0 候选/条 + 事件密度预算 `ceil(1.2×事件/条)`（JSON 里 `*_density` 块）。
- **组级 bootstrap CI**：field split 按 `group`（.fdr 文件组）重采样 B=1000（`--b` 可调），报 F1@20（role-matched）的 NN CI、基线 CI、配对差值 CI；合成 split 无 group → `bootstrap_ci: null`。
- 输出 JSON：`{n_samples, mean_events_per_curve, nn:{role_matched, role_matched_density, role_agnostic, role_agnostic_density, terminal_anchor, terminal_full}, baseline:{同构}, bootstrap_ci}`。
