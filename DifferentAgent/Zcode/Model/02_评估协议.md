# 02 评估协议（冻结版，训练前写死）

> ZCode ｜ 2026-10-30 ｜ 本协议在任何正式训练开始前冻结。改动本文件必须留痕并说明理由，且不允许事后放宽。
> 实现：`evaluate.py`（本目录），任何 split、任何 checkpoint 均用同一段评估代码。
> 背景：12 轮历史迭代中 selection_score 读 test、阈值在 test 上扫、213 条现场曲线被反复吃——本协议的首要目标是杜绝评估污染。

## 一、工作点：固定候选预算

- **主口径：3.0 候选/条**。解码 = 三个非背景角色通道（接头/末端/缺陷）各自取阈值上局部极大值，**25 m 间隔**非极大抑制，跨通道按置信度排序，**只保留预算数个候选**（`cands[:budget]`）。
- **敏感性口径：1.5 与 8.0 候选/条**，仅在汇报时附表展示"命中随预算"的权衡，不用于选型。
- 任何提升若不同时报告候选预算，视为口径操纵，不予采纳（历史教训：阈值 0.5→0.3 使 hit 0.342→0.595 但候选 2.98→10.67）。
- 候选与真值**同角色类一对一匹配**：同容差取距离最近者，已匹配候选不复用。

## 二、定位指标：容差双口径 + 常规输出

- **F1@max(5 m, 2%·d)**（adaptive 口径，随距离放宽）与 **F1@20m**（固定口径）同时报告。
- precision / recall 常规输出，与 F1 一起报，附 tp/fp/fn 原始计数。
- 默认置信度阈值 0.5；**阈值只允许在 field_val 上调，且只允许向高调（提精度方向）**；synth_test 与 blind 上禁止扫阈值。

## 三、按距离分桶

- 命中表按 **250 m 距离桶**输出（`0-250m / 250-500m / ...`，格式"命中/总数"）。
- 用途：检验"远端漏检"是否真的改善（历史 1500 m+ hit 0.196 是核心痛点），防止 macro 指标被近端掩盖。

## 四、末端指标：全分母覆盖率

- 分母 = 该 split 内**所有含可观测末端的曲线**（不是模型给出输出的那些）——**无输出直接计失败**。
- 报告三项：
  1. `terminal_output_rate`：可见性头判定"可见"的比例（输出率）；
  2. `terminal_hit50`：位置误差 ≤50 m 的命中数（分母同上）；
  3. `terminal_mae_m`：可见输出中的位置 MAE。
- 末端是"每条电缆必有且唯一"的事件，全分母口径防止用"不敢输出"刷精度。

## 五、三档报告结构（数据三档）

| 档 | 数据 | 用途 | 规则 |
|---|---|---|---|
| 合成留出 | `synth_val`（template_id%10==0 的模板）+ `synth_test`（%20==10，**封存**） | 训练健康监测 / 合成域泛化 | 模板级留出（同模板的所有实测实现不跨档）；synth_test 不参与任何选型，只在阶段汇报时跑 |
| 现场验证 | `field_val`（`E:\CableNNDataSet\ZCode\field_train` 内 manifest 的 field_val split） | 微调选型、阈值调整的唯一合法集 | 可反复使用，但选型规则写死：按固定预算工作点的 F1@20 选 best.pt |
| 现场盲测 | `blind`（12 相，封存，从未进入任何一轮迭代的训练/验证/选型） | 最终汇报 | **只许在最终汇报时跑一次**；跑完即定稿，不允许据此再改任何东西 |

- 纯合成指标不得作为验收依据（历史：合成 val/test 差 0.005，与现场 hit 完全脱钩）。
- synth_test 与 blind 每阶段最多各消费一次，消费记录写入汇报。

### 五之补记：synth_test 空集修正（2026-10-29）

`generate_dataset.py::split_of` 的两条分支存在包含关系（`t%20==10` 全部满足 `t%10==0`），首个条件先行截走，导致 synth_test 恒为 0 条，初版 DG_V4_S1 实际只有 train 28050 / synth_val 3150。修正采用**只重标 manifest 的 split 列、不重算任何样本**的方式：原 synth_val 中 `t%20==10` 的 1550 条改标为 synth_test，余 1600 条保留为 synth_val。修正后 train 28050 / synth_val 1600 / synth_test 1550，624 个模板无一跨档，模板级隔离成立。

该修正发生在任何正式训练之前，synth_test 此前从未被任何模型读取或消费（空集），故不构成评估污染，也不涉及放宽。**后续对 synth_test 的消费按本条起算。**

## 六、现场组级 bootstrap 95% CI

- 现场指标按**组（电缆/相所属记录组）**重采样（组级 bootstrap，B=1000），报 95% CI。
- 现场规模约 40 个有效点时，CI 粒度约 ±15%：**小于 ±15% 的差异不作为结论依据**；模型间比较必须带 CI 重叠判断，不报裸差值。

## 七、达标线（首轮）

- `field_val` 上 **F1@20 ≥ 0.55**（3.0 候选/条工作点）；
- 末端 **hit@50 ≥ 0.70**（全分母）。
- 参考：历史 12 轮最好成绩为现场非浸水 hit@20 = 0.425（3.0 候选）；首轮达标线即"显著越过历史最好值"。

## 八、操作红线（继承并强化）

1. 阈值只在 field_val 上调，单向（只升不降），调整记录留痕；
2. synth_test / blind 不做阈值扫描、不做模型选择；
3. 选型（best.pt）只看 val loss（合成阶段）/ field_val F1@20（微调阶段），不读 test 键；
4. 每次汇报必须同时给出：候选预算、双口径 F1、precision/recall、分桶表、末端三项；
5. blind 评估命令只允许执行一次（`run_finetune_field.ps1` 末段即该次执行，执行前确认不再迭代）。

## 九、v2 修正案（2026-10-30，第二轮开始前冻结）

第一轮 90 轮长训后（field_val F1@20 0.09 纯合成 / 0.476 含泄漏微调），经用户确认以下修正。**修正不放宽任何第一轮红线，只收紧。**

### 9.1 现场划分重做（作废第一轮 field_val/blind）

- 组 = **.fdr 文件级**（第一轮按相 stem hash 划分，组级泄漏 36%、.fdr 归并口径 98.8%，且 Python hash 跨进程不可复现）。
- 固定 seed=20261030 组级划分 85/15；blind 重新封存（`field_data/blind_groups_v2.json`），**旧 blind 作废留痕，从未被消费**。
- 末端锚定/ txt 全长 >2500 m 的组 → `excluded_long`，不参与训练/验证（项目口径 2.5 km 以下）。
- 第一轮 field_val（85 条）与旧 blind（12 相）的所有历史分数随之作废，不再引用。

### 9.2 达标线：维持数字 + 新增基线条款

- `field_val`（新划分）F1@20 ≥ 0.55（3.0 候选/条）、末端 hit@50 ≥ 0.70（全分母，响应锚定口径）——数字不变。
- **新增**：同一工作点必须显著越过规则法基线（top-k 峰检测 + REF 末端搜索规则，同预算同容差同口径），判定 = NN 与基线的 F1@20 差值的组级 bootstrap 95% CI 下界 > 0。
- 每次评估输出必须附基线对照表。

### 9.3 末端双口径

- 主口径（监督+达标）：响应锚定（模型可学）。
- 并行监控口径：txt FDR 全长位置（用户 2026-10-30 确认；铭牌 plate_m 口径被否定——铭牌≠实测长度）。两口径差值作为波速/校准质量指标监控，不参与达标判定。

### 9.4 候选预算工作点

- 主口径维持 3.0 候选/条、阈值 0.5、NMS 25 m、同角色一对一匹配。
- **新增解码约束**：末端通道每曲线最多贡献 1 个候选（物理事实：每缆一端）。
- 附报口径：事件密度预算 budget=ceil(1.2×事件/曲线)。

### 9.5 选型与监控（混合训练）

- 阶段1（合成预训练 70ep）：best.pt 按 synth_val loss，**且每轮打印 field_val F1@20 监控列**（只监控，不选型）。
- 阶段2（混合微调 30-40ep：field_train + 20-30% 合成回放）：best.pt 按 field_val F1@20。
- blind 只在最终汇报消费一次。

### 9.6 组级 bootstrap 95% CI（第一轮 §六首次强制落实）

- 现场指标按组（.fdr 文件）重采样 B=1000，报 95% CI；模型间/模型-基线比较必须带 CI 重叠判断。
- 有效事件 <50 个时，差异小于 CI 粒度一律不作为结论。
