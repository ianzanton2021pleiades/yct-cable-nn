# DG_V4 变换口径与夹具标定记录

> ZCode ｜ 2026-10-29/30 ｜ 本文档记录两个决定性标定结果，全部有实测验证。

## 一、变换口径：厂商正弦变换（算法2配方）

**结论：.fdr 内嵌的 StepResponse/ImpulseResponse 表与 REF/算法2 的离散正弦变换在 float32 精度内逐点相等（相关系数 0.99999999999，零自由参数）。**

配方（V=1、不减均值、不跳点、不加窗、不做校准，直接用对数栅格）：

```
CL_i = Re(S11_i) / ω_i,   ω = 2πf
step(t) = (2/π)·Σ_i (CL_i+CL_{i+1})/2·[cos(ω_i t) − cos(ω_{i+1} t)] / t
t = linspace(1ns, 3·L_setting/v, 20000)
dist = v/2·t − offset,   offset = v × τ_fixture（文件设置表内嵌，如 −4.3817m）
impulse[k] = (step[k+1]−step[k]) / (Δt·3e8·g),  g = 0.6813（文件内嵌常数）
```

实测验证（三院宿舍770m，A相）：峰位 15.30/18.58/21.27/56.48/91.64/776.37m 逐一相同、峰幅比 0.9999~1.0001、底噪 RMS 比 1.0000。B/C相同样复现。

**含义：**
- DG_V4 的统一变换 = 此配方（`dg_v4/transform.py::vendor_step`），合成/实测同管线，与现场 GUI 逐点同口径；
- 现场数据可直接用内嵌响应表（无需重算）；
- 早期 NUDFT 方案（能复现厂商峰±20%）保留为对照，不再是正式口径；
- 线性插值+IFFT 路线被实测证伪（远端峰全灭），弃用。

## 二、夹具模型：实测S参数标定

数据源：`REF\S参数：典型采样数据分析` 两个zip（解压于 `AgentsStorage/ZCode_fixture_sparam/`，分析脚本同目录）。

| 参数 | D型（SMA+2×20cm引线+鳄鱼夹，现场主力） | E型（鳄鱼夹直连） |
|---|---|---|
| 等效线阻抗 | ≈66Ω | ≈200Ω |
| 电学时延 | 23.2ns（S21实测，双向自洽） | 3.6-4.3ns |
| 尖端附加电容 | 30-150pF（开路总C=455pF−线C≈349pF） | 0-10pF |
| 串联电阻 | 0.7-1.1Ω | 0.1-0.3Ω |
| 单程损耗@100MHz | 1.0-3.3dB，√f律 | 1.2-2.2dB |

物理机制确认：**中频0.81-0.82平台 = 尖端大电容+高阻引线与低Z0电缆（12-32Ω相地模）的接口失配**；高频衰减 = 夹具√f损耗。医院文件内嵌 offset=−4.3817m ⟺ τ_fixture=25.5ns，与D型实测23.2ns吻合——现场测试确实带引线。

## 三、现场参数拟合（fit_field.py，DE全局拟合）

固定 εr=3.037（五个文件独立拟合一致收敛 3.03-3.04 ⟹ 波速172m/µs），拟合 Z0/α/夹具/粗糙度/接头幅度。结果与冻结的范围见 `dg_v4/topology.py::P` 与 `dg_v4/measurement.py::_RANGES`。

关键数字（对历史失败的修正）：
- 电缆 Z0（相地模）12-32Ω（历史 42-75Ω 错误）；
- α@100MHz 0.01-0.03 dB/m（受控反演0.02，历史0.62差31倍）；
- 短路归一化 Γ_raw/Γ_short 必须用"夹具尖端短路"（曾误用电缆末端短路导致 |S11|>1.6 非物理值）。

## 四、遗留观察

- 实测 0.1-3MHz 有 0.56-0.62 的凹谷（夹具LC串联谐振带），模型可部分复现；
- 厂商变换只用 Re(S11)（正弦变换），虚部信息经另一路（阶跃）进入判读——标签锚定在 impulse 峰位与两个域联用；
- 对数栅格高频端物理欠采样（对2km+电缆）造成折叠杂波，这是数据属性，厂商/我们同样面对，模型必须学会在此底噪上检测。
