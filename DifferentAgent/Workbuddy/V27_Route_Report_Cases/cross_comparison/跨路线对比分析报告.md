# 跨路线对比分析：V2.7 路线 vs DG V3 / CST V1

- 运行时间：23.07 s
- 数据来源：本实验 output（V2.7 RG58/Field 路线）与 CodeX/DG_Route_Evaluation output（dg_v3_rlgc、cst_v1_ladder_0p1m、cst_v1_continuous），全部只读。
- 两侧共用 9 kHz–200 MHz / 10000 点频率网格；common_measurement 层使用同一噪声实现（seed = 20260902 + 工况序号），距离域响应均由各自 S11 计算。
- 注意：V2.7 两条路线使用各自的介质参数（50 Ω、epsr 2.23/2.3），CodeX 候选在 100 MHz 锚定报告一次 RLGC（Z0≈137 Ω、40 pF/m），因此 S11 绝对形态不同属预期，对比重点是工况方向性与事件定位的一致性。
