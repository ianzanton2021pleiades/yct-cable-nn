# 现场 FDR、数据集生成链路与当前训练数据调研

日期：2026年10月23日；调研：CodeX，GPT-6 Luna Max 分工核查。范围：项目现有资料、`E:\20261010截至的全部fdr文件`、`E:\CableNNDataSet`、Workbuddy 当前训练进程及其脚本/配置/日志。源数据、数据集、训练文件全部只读。

## 一、调研结论

**项目已经有较详细的现场 FDR/S11 分析；目前数据集形成了“物理合成—响应缓存—现场弱监督—实测背景注入—候选 patch”几条明确的数据链。当前 Workbuddy 正在运行的 `pinn200_phase4` 使用的是 Iter4 合成响应缓存，通过真实夹具短接库增强；不是直接使用 Hybrid_Long 现场注入集进行训练。**

你上周整理的案例资料已经被利用，但用途有区别：长度和接头位置进入筛选及弱标签；原始复数 S11 可作统计、拟合和 Hybrid 的真实背景；短接数据形成夹具扰动库和短接监督样本。绝缘电阻、介损、振荡波、试验后状态主要保留为案例佐证，当前数据链没有把它们系统转换为逐相、逐次测量的结构化训练标签。

本报告集中回答“已有工作是什么、各数据集是什么、当前训练吃什么数据”。不足及其影响集中放在同目录《02_不足限制与边界.md》。用户已确认以188个现场FDR文件为本轮正式口径，下文分别列出文件、曲线与案例数量。

通用`real_manifest`保留213条来源与范围，标签状态均为unknown；独立的Iter5人工证据台账有177项记录，覆盖60个案例，其中50个案例有位置证据，10个只有长度或结论。后续弱监督读取独立证据表，因此通用manifest的unknown不等于人工整理没有被使用。

原始现场资料首先是“带来源的测量与试验档案”，之后才由不同脚本提取各自所需字段。当前模型输入主要仍为由S11得到的响应特征，而不是把绝缘、介损数值拼接成网络输入。

## 三、E盘各数据集的真实生成链路

### 3.1 总体组织

`E:\CableNNDataSet` 下实际有 CodeX、Deepseek_CMDC、WorkBuddy 三个一级目录。WorkBuddy 数据目录为空；Workbuddy 当前训练跨目录复用 CodeX 的缓存。代理名称是文件组织方式，不是独立数据生成方法。

### 3.3 物理合成主链

主链为：

**随机电缆长度/拓扑与异常 → 分段频变RLGC → 接头/末端/夹具网络 → 复数S11 → Algorithm1空间响应 → 特征与监督目标。**

首轮FieldNN沿用Core16现场探索参数，实际调用本项目`Core16_Field/field_physics.py`的`simulate`，路线名为`dg_v3_rlgc`。这个名称不表示直接运行`DG_Update/DG_V3`的原生批量生成器；判断应以实际函数调用为准。Iter3随后把主材料改为联合损耗预算：先抽取特性阻抗、波速、100MHz总衰减目标和介质损耗占比，再约束导体与介质损耗的配合；保留10%的旧高损耗锚点。配置还随机化接头、参考面延迟、近端网络、复测量误差及相关噪声。

Iter3具体配置：长度100–2500m，四个长度区间；频率9kHz–200MHz、32768个对数点；模型响应轴0–3250m、8192点，名义速度172m/μs；30%零事件健康机制样本，10%仅接头样本。这里3250m是响应观察范围，不是把训练电缆扩展到3250m。

监督区分几何物理真值和可观测响应位置：事件/末端标签由传播核与可辨性规则形成，配置限制事件主瓣宽度20m、末端40m，并使用核SNR阈值5。Iter4继承这套S11和标签，将原始脉冲/阶跃缓存下来供在线增强，没有再生成另一批物理电缆。

### 3.4 现场响应缓存与候选patch链

Iter6以213条短线清单为来源，其中138条进入弱正例特征缓存，train/val/test为65/31/42条，组织为21/10/21个“适用扫频袋”。它按源波速把记录位置换算到模型名义距离轴，并把明确复测关系归组。Iter8增加90m、300m尺度的阶跃特征，并准备63份有效夹具短接，划分39/12/12。

Iter9将上述138条缓存与其余75条重算合并为213条，再在整条响应上提候选、裁patch。其summary记录52个现场证据袋、163个已知正例位置，以及校准候选3453个。它属于“候选表示与监督组织”的改变，不是新一代S11物理生成器。

### 3.5 实测背景注入Hybrid链

Hybrid保留真实S11的夹具、噪声、频响和原有反射背景，向其中叠加带限反射：

`Γ注入(f)=A·exp(−2π²f²σt²)·exp(−j4πfd/v)`，`σt=2σd/v`。

单反射宽度σd为3–35m，幅度按局部响应背景定标，目标峰值/背景比1.2–8；注入位置避开已知工程师位置40m，事件间距至少60m。区间异常用相距20–100m的反号反射对表示，再加平滑复增益/相位纹波、约±2m时移和复噪声。

监督来自三处：注入位置提供精确的人工构造标签；高置信工程师位置提供弱正例；无被测电缆的短接提供限定范围的负例。Hybrid_Long主要增加同背景上的训练注入变体，不是新增2530条独立现场电缆。

### 4.2 一条训练样本如何得到

1. 从Iter4缓存读取合成电缆的原始脉冲、阶跃和目标；这些缓存追溯到Iter3的物理复数S11。
2. 复用Iter5数据视图，对响应进行展宽、距离增益等变换；引入真实短接近端扰动，形成现场形态增强视图，同时以35%概率保留clean replay。
3. 在此基础上施加当前命令指定的距离warp幅度 `±1%`（触发概率50%）和mixup概率 `20%`，以及默认30%概率的指定通道特征噪声，再构造输入特征。位置和目标随增强规则同步处理。
4. 训练集在线随机增强；验证集使用对应固定视图。9600/1200是底层缓存样本数，在线变化不代表新增独立电缆。

### 4.3 现场数据在这次训练中扮演的角色

| 数据 | 当前是否读取 | 作用 |
|---|---|---|
| Iter4合成train/val响应 | 是 | 当前训练与验证的主体 |
| 6份开发来源CalibrationData响应 | 经增强类读取 | 夹具短接近端扰动库，进入增强样本 |
| Hybrid_Long注入数据 | 当前train_pinn.py未读取 | 项目另有后续finetune_field.py入口 |
| 全部已标注现场电缆与试验数值 | 当前训练未直接读取 | 由其他缓存/评价与后续适应流程使用 |

所以，“Workbuddy使用了现场数据”在当前训练中的精确含义是：**以合成电缆响应为主体，利用真实夹具短接响应进行增强**。真实电缆背景注入是另一条已经存在的数据路线，不能把两者合并描述。

## 五、综合判断

现有现场整理成果已经形成可用资产：有原始S11、短接对照、受控浸水试验、工程师位置、维修与其他试验记录。数据利用也已经从单一纯合成拓展到四种实质方式：统计约束、少量等效拟合、响应域增强/弱监督、真实背景注入。

对DG改进最有价值的下一步，是让这些资料的来源、相别、测量时序和用途在同一份案例记录中对应起来，再按“用于材料/近端约束、用于训练监督、用于独立评价”明确分工。当前不需要为了完成本次调研重新生成数据或打断正在进行的训练。
