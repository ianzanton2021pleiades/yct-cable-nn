## 已确认的处理

- 消费者阅读版直接读取FDR中的厂商阶跃/脉冲表，缺表时自动加载不补算。
- 平滑参数K传入居中移动平均，半径为整数除法K/2，边界缩窗。K=2实际为内部3点，K=15/75分别为15/75点，K<=1原样复制。
- Y偏移只改变绘图点的纵坐标，不改变Sweep原始响应数组。
- 当前选中测次可用Ctrl+R触发显式重新计算。该路径调用Analyser.Arithmetic.GetResponse和厂商原生DLL，随后保存阶跃/脉冲表，会写当前FDR。
