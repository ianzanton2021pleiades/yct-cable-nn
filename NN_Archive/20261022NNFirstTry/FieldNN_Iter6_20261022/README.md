# FieldNN Iter6：现场弱标签适应

本轮保留 U-Net、Transformer 两种结构，从 CMDC Iter5 的最佳权重继续训练。优先解决训练监督与现场响应不一致的问题，不增加第三模型，不重新生成整套合成 S11。

## 一条命令执行

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File "D:\GitRepository\Cable-NN\NN_Archive\20261022NNFirstTry\FieldNN_Iter6_20261022\run_iteration6.ps1"
```

流程：读取现场原始 FDR → 生成分组弱标签缓存 → 依次训练两模型 → 合成验证集校准阈值 → mixed/clean 合成测试 → 全现场推理 → 与 Iter5 固定工作点配对评价。

默认使用 `E:\Anaconda\envs\gpushare_cu124\python.exe`，最多18轮，batch 64，6个训练数据加载进程。启动器限制在7个物理核心范围，保留1个物理核心；两模型顺序使用同一GPU，不修改显卡配置。训练显示进度条，保存逐轮损失、梯度、AMP跳步、吞吐、显存与恢复状态。

中断后在相同命令末尾加 `-Resume`。只训练一种模型可加 `-Models unet` 或 `-Models transformer`。需要降低显存时显式加 `-BatchSize 32`。

## 数据和监督

- 原始现场目录 `E:\20261010截至的全部fdr文件` 只读。新缓存位于 `E:\CableNNDataSet\CodeX\FieldNN_Iter6_20261022`。
- 合成数据复用 Iter4 原始响应缓存及 Iter5 在线增强，不改动旧数据；合成样本继续提供事件、区间、末端完整监督。
- 现场仅采纳能匹配源FDR及适用扫频的高置信工程师位置记录，排除明确坐标冲突和已知长度超过2.5km的案例。
- 以电缆、案例、源文件和已知复测关系构成的连接组划分训练/验证/保留测试。校准夹具开发来源归训练侧；1500m浸水实验整组留在测试侧。
- 每条证据组成适用扫频的候选袋。位置附近只要求至少一条适用扫频出现响应，不把所有相别都强行标成正例；未标注区域不是负例。工程师点位窗口半径20m，来源为TDR估计的特定案例40m，已知实验10m；按各源文件波速映射回模型坐标。
- 每个合成训练步回放完整合成监督，每2步加入一个现场袋。现场损失为已知位置的正例多实例损失，加冻结Iter5教师在未标注区域的软预测保持损失。教师预测不当作真实标签。
- 学习率3e-5；按合成验证损失及现场验证正例损失的归一化组合选权重。原Iter5权重也参与最佳选择；没有改善时允许保持原模型。

## 结果怎么看

主入口为 `output/iter6/iteration6_summary.json`，分阶段日志在 `output/iter6/logs/`。每模型保存 `best.pt`、`last.pt`、`history.csv`、`thresholds.json`、合成测试结果及现场预测图。

`output/iter6/paired/field_comparison_<model>.json` 在相同现场扫频上比较 Iter5 和 Iter6，固定 event/interval/terminal 阈值为0.6/0.99/0.4。新模型另有仅从合成验证集校准的工作点，避免把阈值改变当作训练增益。

现场评价采用10/20/30m容差的一对一匹配，分别给出逐扫频、每证据袋最佳单条扫频、独立组宏平均和候选密度。不同起测原点、不同湿接头条件只共享数据划分，不混合位置标签。1500m实验独立显示。

现场记录是局部正例证据，没有完整负例真值，不能据此声称现场precision/recall；额外候选均为未核实。这批213条曲线此前已用于多轮开发，本轮保留组只保证没有参与Iter6现场标签训练，不是全新盲测。为保持配对比较，本轮保留Iter5的30m首端屏蔽，因此不评价该区域的实际缺陷检出能力。

短链路产物仅用于确认代码、梯度、显存和评价接口；正式运行结果出来前，不宣称Iter6现场精度提升。
