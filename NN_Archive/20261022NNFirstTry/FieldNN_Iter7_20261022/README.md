# Iter7：集中约束现场未标注区域的高响应

Iter6 固定阈值下命中增加，但候选也大量增加。仅使用现场验证组选择阈值，使候选密度不高于 Iter5 后，非浸水测试组的组平均已知位置命中率仅有小幅改善，1500m 浸水实验的 Transformer 还回退。因此本轮针对候选漂移做一个损失函数对照。

## 运行

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File "D:\GitRepository\Cable-NN\NN_Archive\20261022NNFirstTry\FieldNN_Iter7_20261022\run_iteration7.ps1"
```

中断后加 `-Resume`。默认两个模型顺序执行，batch64、6个加载进程，保留1个物理核心，最多18轮并早停；不改GPU配置。

## 本轮唯一实验变量

仍使用 Iter5 最佳权重作为初始化，与 Iter6 保持相同的模型结构、数据划分、合成回放、现场正例多实例损失、学习率和随机种子。直接读取现有 Iter4 合成缓存及 Iter6 现场缓存，不重建数据。

Iter6 的教师保持损失把稀疏事件与大量背景一起平均。Iter7 对每条现场曲线，在已知正例窗口及原有扩展范围外，按学生或教师的较高响应选128个bin，以教师概率作为软目标计算事件KL；区间、末端继续采用全网格加权KL，三头等权。128是采样网格点数，不是128个独立事件；未标注位置仍然不是无缺陷真值。

## 结果与判定

结果位于 `output/iter7/iteration7_summary.json`，包含训练记录、验证校准、合成mixed/clean测试和现场固定阈值对比。现场固定工作点保持event/interval/terminal为0.6/0.99/0.4，并与Iter5、Iter6比较相同扫频和位置证据。

默认两个模型完成后，自动进行验证组候选密度匹配，再评测试组；`density_analysis.json` 记录选定阈值及非浸水测试组、1500m实验的结果。候选增加下的命中提高，不能单独判为本轮成功。单模型运行仍输出固定工作点比较，不生成双模型密度报告。

现场仅有局部正例证据；使用过的213条曲线也不是全新盲测。保留逐扫频与组平均指标，额外候选按未核实处理，不据此计算现场precision。30m首端屏蔽继承既有比较口径，该范围内的真实缺陷检出不在本轮结论内。

短检查只执行每模型3个训练batch，确认第二次现场更新中的教师项已被实际计算；短检查不代表正式效果。
