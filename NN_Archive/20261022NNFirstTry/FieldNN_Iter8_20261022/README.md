# Iter8：宽尺度阶跃输入与真实短接监督

## 运行

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File "D:\GitRepository\Cable-NN\NN_Archive\20261022NNFirstTry\FieldNN_Iter8_20261022\run_iteration8.ps1"
```

一条命令完成：现场特征重算、短接数据准备、两模型训练、合成验证校准与测试、短接伪事件评价、213条现场推理、Iter5/Iter7/Iter8比较及验证组候选密度匹配。中断后加 `-Resume`；仅跑一种模型可加 `-Models unet` 或 `-Models transformer`。

默认最多18轮、早停5轮、batch64、6个加载进程，启动器保留1个物理核心，两模型顺序使用GPU。新数据在 `E:\CableNNDataSet\CodeX\FieldNN_Iter8_20261022`，结果在 `output/iter8`。原始FDR和旧数据不改，不重新生成合成S11。

## 改动依据

Iter7在固定阈值下仍有候选膨胀；限制候选预算后，远端湿接头没有稳定改善。小样CPU形态分析发现，700–1100m弱反射的脉冲局部RMS对比接近1，而原30m阶跃去趋势特征削弱了宽缓变化。

因此保留原8通道，再增加90/300m两尺度的阶跃去趋势/全局RMS与阶跃去趋势/局部RMS，共12通道。U-Net/Transformer前加12→8的线性输入层，初始前8通道恒等、新4通道权重为0，再加载Iter5最佳主干；输入层与主干学习率分别3e-4、3e-5。

用户已确认FDR的`CalibrationData`是夹具短接、未接被测电缆。准备器排除空表、独立频点不足或不覆盖9kHz–200MHz的校准表，并在`calibration_summary.json`记录原因。本轮有效63份：train39、val12、test12；1500m实验文件为空，另3份校准表的10000行均为9000Hz，不能用于宽带变换。现场测量曲线仍保留。30m外监督“没有被测电缆事件/缺陷区间”，首端与全部terminal标签忽略。这些是短接参考，不是健康电缆。

训练保留合成完整监督、现场正例MIL；每2步加入现场正例袋与8条短接参考，各权重0.5。短接事件损失聚焦128个高响应网格点，区间采用全域有效点负例损失，替代Iter7的冻结教师KL；真实电缆未标注区域仍然未知。选择权重使用合成验证、现场正例验证与短接验证损失，未使用测试结果选权重。

本轮属于输入与监督的联合探索，不能把改善单独归因于某一项。

## 结果判断

- 主入口：`output/iter8/iteration8_summary.json`；日志在同目录`logs/`。
- `paired/field_comparison_<model>.json`：固定0.6/0.99/0.4阈值的现场对照。
- `density_analysis.json`：仅按现场验证组选阈值，再评价非浸水保留组和1500m实验。候选预算限制不等于precision。
- `<model>/calibration_baseline5.json`和`calibration_iter8.json`：确认短接参考上的伪电缆事件计数；终端不评分。

短链路只验证执行与数值，不证明现场效果。既有213条曲线已经多轮用于开发，保留组是训练标签隔离，不能称为全新盲测；30m首端屏蔽继续沿用，不能宣称该区域可检出。
