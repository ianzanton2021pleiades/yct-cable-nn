本轮改变问题建模方式：物理前端先提出候选位置，两个局部网络再给候选评分。保留Iter8 U-Net作为现有对照，不替换GUI、不改DeepSeek的目录或任务。

## 归档状态

本路线已停止，不再继续训练。原运行命令和参数不再作为可执行入口；本目录保留本 README、`CONTRACT.md`、候选生成与审计代码及已有输出，作为方法与结果记录。瘦身后不再具备 Iter9 模型训练/评价链。

## 当前可保留的结果

既有Iter8 U-Net在6个非浸水保留组、40个位置记录上，验证组候选预算校准后命中17/40，组平均hit@20m为50.9%，候选3.00条/曲线；Iter5为13/40、39.9%、3.03条/曲线。1500m实验仍7/11。Transformer本轮没有相应稳定增益。结果图为 `Image/20261022_FieldNN_Iter8_progress.png`。

这些是局部正例证据，不是现场完整precision/recall。这批数据已多轮用于开发，不称为全新盲测。

## 新路线

1. 脉冲30/90m局部对比、阶跃90/300m宽变化四类分数各取最多20个峰，相距10m内合并。跨分数图使用各图相对强度，验证/测试不注入已知标签位置。
2. 每个候选提取±50m、±200m两个视野，重采样为20通道×256点。只保留波形与中心相对坐标，去掉全轴绝对位置及恒定全局RMS通道，减少记忆案例位置。
3. 小型U-Net与Transformer从头训练，每个候选一个event logit。本轮只研究事件定位，不声称区间/末端模型改善；可观测的合成末端作为非缺陷候选监督，以区分末端和内部事件。
4. 合成候选有完整正负监督；现场标注位置继续以适用扫频/候选组成MIL正例袋；真实电缆其他候选保存为unknown；用户确认的短接参考提供明确无被测电缆事件样本。

## PU统计假设

用户已选择PU。默认正类先验 `pi=0.1` 是训练假设，**不是估计得到的现场缺陷比例**。损失为：

`synthetic_BCE + 0.5*positive_bag_BCE + [pi*E_P softplus(-z) + max(0,E_U softplus(z)-pi*E_P softplus(z))] + 0.25*calibration_BCE`

P用每个正例袋的最大logit近似，U来自全部训练现场候选、包含潜在正例；按连接组均衡采样。由于工程师标注与bag-max存在选择偏差，这属于弱正例袋PU目标，不宣称满足标准PU的无偏风险假设。未标候选不写成硬负标签。不默认进行多先验大规模搜索，避免额外训练占用。

## 如何判断是否成功

- 数据准备后先输出 `proposal_coverage_before_training.json`：只是候选覆盖上限，不能当网络检出率。未被提出的已知位置仍计漏失，不从评价真值中删掉。
- 每轮只用field val在统一Iter5 U-Net候选预算下选阈值；checkpoint按验证组已知位置macro hit减短接伪事件惩罚选择，不再按positive MIL损失选择。
- 最佳权重锁定后才评价test。正式结果在 `output/iter9/iteration9_summary.json`；每模型的`evaluation/field_report.json`分开非浸水组、1500m实验和未知曲线候选数；`field_comparison.json`对比Iter5/Iter8/Iter9。
- `synthetic_patch_report.json`是候选分类指标，不能与旧整曲三头F1直接比较。最终是否保留新模型取决于相近候选负担下的现场证据，不能只看loss或物理候选覆盖。
