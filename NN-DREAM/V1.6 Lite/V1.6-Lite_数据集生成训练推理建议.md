# V1.6-Lite 数据集生成、训练与推理建议

## 一、数据集生成的总原则

V1.6-Lite 数据集生成器要服务三个目标。

第一，支持时延端点分支训练。所以必须有总长度 $L_{\mathrm{tot}}^{gt}$，并能自动派生末端端点热力图 $y_{\mathrm{end}}(\tau)$。端点标签由 $\tau_{\mathrm{end}}^{gt}=2L_{\mathrm{tot}}^{gt}/\bar v_0$ 给出，并通过 $y_{\mathrm{end}}(\tau)$ 监督时延端点头。

第二，支持缺陷候选和 slot 训练。所以必须有真实缺陷列表，至少包括每个缺陷的起点 $x_u^{start}$ 和长度 $l_u$。V1.6-Lite 已经使用真实缺陷位置生成 $y_D(\tau)$，并且模型输出 $x_k^{start}$ 和 $l_k$，因此数据生成器层面必须显式保存缺陷长度，否则 $w_D$、$l_k$ 和 $\mathrm{MAE}_l$ 都会失去可靠来源。

第三，支持低维物理参数头学习。所以仿真数据必须保存 $\delta_{\alpha,G}^{gt}$、$\delta_{\varepsilon,G}^{gt}$、$\delta_{\alpha,k}^{gt,eff}$、$\delta_{\varepsilon,k}^{gt,eff}$。这些变量正是 V1.6-Lite 的全局背景变量和局部缺陷等效扰动变量。如果这些标签不保存，模型仍可通过 $S_{11}$ 频域损失训练，但物理语义更容易漂移，尤其容易出现损耗扰动、介电扰动和全局背景扰动互相代偿的问题。

因此，仿真数据生成器的基本原则是：**标签必须完整保存，训练可以分层使用**。总长度、缺陷起点和缺陷长度是主强监督标签；Lite 等效物理扰动是仿真辅助监督标签；Full 物理扰动、Near 残差和末端残差是必须保存的扩展真值，不一定在阶段二主模型中直接强监督。

## 二、数据集标签与元数据清单

### 2.1 必须保存的输入数据

每条样本必须保存原始频域观测：

```yaml
frequency_hz: [...]
s11_real: [...]
s11_imag: [...]
```

这三项对应 $f_i,\operatorname{Re}(S_{11,i}),\operatorname{Im}(S_{11,i})$，是频域主分支、IFFT 预处理和物理一致性损失的共同基础。不能只保存 IFFT 后的时延数据，也不能只保存网络输入特征。

### 2.2 必须保存的电缆规格先验

每条样本必须保存电缆名义规格：

```yaml
cable_spec:
  core_area_mm2: ...
  shield_inner_radius_mm: ...
  core_material: ...
  shield_material: ...
  insulation_material: ...
  eps_r_0: ...
  tan_delta_0: ...
  sigma_core_0: ...
  sigma_shield_0: ...
  g_0: ...
  v0_m_per_s: ...
```

这些字段对应 V1.6-Lite 中的 $\mathbf{m}$、$r_{c,0}$、$g_0$、$\sigma_{c,0}$、$\sigma_{s,0}$、$\varepsilon_{r,0}$ 和 $\tan\delta_0$。它们不只是说明信息，而是物理层计算 RLGC 的名义基线。即使当前阶段只做单一电缆规格，也建议显式保存，避免后续换规格或做消融时无法回溯。

### 2.3 主强监督标签

这部分是第一版训练绝对不能缺的标签。

```yaml
length_m: 1200.0

defects:
  - defect_id: 1
    x_start_m: 350.0
    length_m: 8.0
    x_end_m: 358.0
    x_center_m: 354.0
```

数学形式为 $L_{\mathrm{tot}}^{gt}$、$\mathcal{D}^{gt}=\{(x_u^{start},l_u)\}_{u=1}^{N_D}$，其中 $N_D$ 是真实缺陷数量，$x_u^{end}=x_u^{start}+l_u$，$x_u^{center}=x_u^{start}+l_u/2$。

健康样本必须写成：

```yaml
defects: []
```

不要省略 `defects` 字段。省略字段和空列表在 dataloader 中很容易被错误区分，后期会造成健康样本处理混乱。

这部分用于监督总长度估计 $\hat L_{\mathrm{tot}}^{NN}$、末端端点热力图 $y_{\mathrm{end}}(\tau)$、缺陷候选热力图 $y_D(\tau)$、候选宽度 $w_D(\tau)$、slot 存在性 $q_k$、缺陷起点 $x_k$ 和缺陷长度 $l_k$。

### 2.4 Lite 等效物理标签：必须保存，建议辅助监督

仿真数据必须保存：

```yaml
global_lite_params:
  delta_alpha_G: ...
  delta_epsilon_G: ...

defects:
  - defect_id: 1
    x_start_m: 350.0
    length_m: 8.0
    lite_params:
      delta_alpha_eff: ...
      delta_epsilon_eff: ...
```

对应 $\delta_{\alpha,G}^{gt}$、$\delta_{\varepsilon,G}^{gt}$、$\delta_{\alpha,k}^{gt,eff}$ 和 $\delta_{\varepsilon,k}^{gt,eff}$。

这部分不建议压过频域物理一致性损失，但必须作为仿真辅助监督。原因很简单：V1.6-Lite 的物理头输出就是这些变量，如果不保存它们，模型可能学出可拟合但语义不稳定的低维参数。

### 2.5 Full 物理扰动标签：必须保存，但 Lite 阶段不一定直接监督

如果生成器内部使用了更细的物理扰动，必须保存：

```yaml
global_full_params:
  delta_sigma_G: ...
  delta_tandelta_G: ...
  delta_g_G: ...

defects:
  - defect_id: 1
    full_params:
      delta_sigma: ...
      delta_tandelta: ...
      delta_g: ...
```

对应 $\delta_{\sigma,G}^{gt},\delta_{\tan\delta,G}^{gt},\delta_{g,G}^{gt}$ 和 $\delta_{\sigma,k}^{gt},\delta_{\tan\delta,k}^{gt},\delta_{g,k}^{gt}$。

这些标签在 V1.6-Lite 阶段二中不一定直接监督，因为 Lite 主模型没有单独输出 $\delta_\sigma$、$\delta_{\tan\delta}$ 和 $\delta_g$。但是必须保存，原因有四个：后续 V1.6-Full 需要直接使用；可以分析 Lite 模型对不同物理原因的误差；可以把 Full 扰动投影成 Lite 等效标签；可以保证每条仿真样本可追溯。

如果底层生成的是 Full 变量，而 Lite 只输出 $\delta_\alpha$ 和 $\delta_\varepsilon$，建议额外保存投影后的等效标签 $\delta_{\alpha,k}^{gt,eff}$ 和 $\delta_{\varepsilon,k}^{gt,eff}$。其中 $\delta_{\varepsilon,k}^{gt,eff}$ 可以直接由介电常数变化定义为 $\delta_{\varepsilon,k}^{gt,eff}=\log(\varepsilon_{r,k}/\varepsilon_{r,bg})$；而 $\delta_{\alpha,k}^{gt,eff}$ 更适合通过 Lite 等效拟合获得，不建议简单把 $\delta_\sigma$ 或 $\delta_{\tan\delta}$ 直接硬映射过去。

### 2.6 Near/End 标签：必须保存，阶段二谨慎启用

仿真数据必须保存：

```yaml
near_end:
  near_case_id: near_001
  R_N_cal: ...
  L_N_cal: ...
  C_N_cal: ...
  delta_R_N: ...
  delta_L_N: ...
  delta_C_N: ...
  end_case_id: open_001
  C_end_cal: ...
  delta_C_end: ...
```

对应 $R_N^{cal},L_N^{cal},C_N^{cal}$、$\Delta R_N,\Delta L_N,\Delta C_N$、$C_{end}^{cal},\Delta C_{end}$。

V1.6-Lite 中 Near 模块和末端边界都采用校准主值，真实数据微调阶段才引入小范围残差。所以阶段二主训练建议默认冻结 Near/End 残差，仅保存标签；后期消融或真实微调时再以低学习率、强先验启用。

### 2.7 频率元数据：必须保存

每条样本必须保存：

```yaml
freq_meta:
  f_min_hz: ...
  f_max_hz: ...
  num_points: ...
  step_hz: ...
  bandwidth_hz: ...
```

$F_{\mathrm{ifft\_full}}$ 预处理日志必须记录 $f_{\min}$、$f_{\max}$、频点数 $M$ 和 $step\_hz$，用于保证 IFFT 候选、阶跃端点读取和距离解释一致。如果这里漏了 $step\_hz$，后面 IFFT 距离轴、末端位置、缺陷位置全都会有潜在错误。

### 2.8 自动派生标签

这些不一定要作为原始 YAML 字段保存，但必须由数据预处理或 dataloader 版本化生成。

由 $L_{\mathrm{tot}}^{gt}$ 自动派生 $\tau_{\mathrm{end}}^{gt}=2L_{\mathrm{tot}}^{gt}/\bar v_0$，$y_{\mathrm{end}}(\tau_n)=\exp[-(\tau_n-\tau_{\mathrm{end}}^{gt})^2/(2\sigma_{\mathrm{end}}^2)]$。

由缺陷列表自动派生 $x_u^{center}=x_u^{start}+l_u/2$，$\tau_u=2x_u^{center}/\bar v_0$，$y_D(\tau_n)=\max_u\exp[-(\tau_n-\tau_u)^2/(2\sigma_u^2)]$，其中 $\sigma_u=\max(\sigma_{\min},2l_u/\bar v_0,c_\Delta\Delta\tau)$。

候选宽度标签为 $w_u^{gt}=2l_u/\bar v_0$。slot 匹配标签为 $\operatorname{match}(k,u)=\mathbb{1}(|x_{k,\mathrm{anchor}}-x_u^{center}|<r_{\mathrm{match}})$；匹配成功时 $q_k^{gt}=1,x_k^{gt}=x_u^{start},l_k^{gt}=l_u$，未匹配时 $q_k^{gt}=0$，未匹配槽位不要监督 $x_k,l_k,\delta_{\alpha,k},\delta_{\varepsilon,k}$。

## 四、样本分布建议

### 4.1 缺陷数量分布

阶段二虽然使用 $K_{\max}=5$，但训练数据不应该均匀生成 0 到 5 个缺陷。建议：

| 真实缺陷数 $N_D$ | 比例 |
|:---|:---|
| 0 | 30% |
| 1 | 35% |
| 2 | 20% |
| 3 | 10% |
| 4 | 4% |
| 5 | 1% |

这样可以让模型以健康、单缺陷、双缺陷为主体，同时保留多缺陷能力。均匀生成 0 到 5 个缺陷会人为提高多缺陷先验，导致 $q_k$ 虚高、误报率上升。

### 4.2 健康样本必须包含 hard negative

健康样本内部建议：

| 健康样本类型 | 健康样本内比例 |
|---|---:|
| 理想健康 + 轻噪声 | 20% |
| 全局介电常数偏移 | 25% |
| 全局损耗偏移 | 20% |
| Near 轻微残留 | 15% |
| 末端边界变化 | 10% |
| 背景波纹或弱伪峰 | 10% |

这里非常关键。$K_{\max}=5$ 给了模型更多槽位，如果 hard negative 不足，它会把背景波纹、末端旁瓣、Near 残留当成缺陷。

### 4.3 总长度分布

阶段二面向 $\leq2.5\ \mathrm{km}$，建议：

| 总长度范围 | 比例 |
|---|---:|
| $50$ 到 $300\ \mathrm{m}$ | 10% |
| $300$ 到 $800\ \mathrm{m}$ | 20% |
| $800$ 到 $1500\ \mathrm{m}$ | 30% |
| $1500$ 到 $2500\ \mathrm{m}$ | 40% |

阶段三扩展到 $5\ \mathrm{km}$：

| 总长度范围 | 比例 |
|---|---:|
| $2500$ 到 $3500\ \mathrm{m}$ | 40% |
| $3500$ 到 $4500\ \mathrm{m}$ | 40% |
| $4500$ 到 $5000\ \mathrm{m}$ | 20% |

你的任务重点是长电缆，不要让短电缆样本占主体。

### 4.4 缺陷位置分布

建议按距离分层：

| 缺陷位置段 | 比例 |
|---|---:|
| 近端排除窗外到 $0.2L$ | 20% |
| $0.2L$ 到 $0.5L$ | 30% |
| $0.5L$ 到 $0.8L$ | 30% |
| $0.8L$ 到 $0.95L$ | 20% |

不建议大量生成 $x>0.97L$ 的缺陷，因为靠近末端的缺陷与开路端反射耦合严重，标签可辨识性差。少量放进困难测试集即可。

### 4.5 缺陷长度分布

建议：

| 缺陷长度 | 比例 |
|---|---:|
| 小于距离分辨率 $\Delta z$ | 5% |
| $5\Delta z$ 到 $15\Delta z$ | 40% |
| $15\Delta z$ 到 $30\Delta z$ | 40% |
| 更长缓变段 | 15% |

其中 $\Delta z\approx v_p/(2B)$。对于 $l_u<\Delta z$ 的缺陷，不要强求长度精确回归。训练时应降低长度损失权重，重点监督位置和存在性。

### 4.6 物理扰动分布

Lite 等效扰动建议分层采样，不要全均匀。全局背景可先取 $\delta_{\varepsilon,G}\in[-0.05,0.05]$、$\delta_{\alpha,G}\in[-0.1,0.1]$。局部缺陷建议分为弱缺陷、中等缺陷和强缺陷，其中弱缺陷占 40%，中等缺陷占 45%，强缺陷占 15%。不要让强缺陷占主体，强缺陷太多会让时延候选过于容易，实测弱缺陷召回会差。

Full 扰动要分类型保存：

| 类型 | 主扰动 |
|---|---|
| 介电扰动 | $\delta_{\varepsilon,k}$ |
| 介质损耗扰动 | $\delta_{\tan\delta,k}$ |
| 导体损耗扰动 | $\delta_{\sigma,k}$ |
| 几何扰动 | $\delta_{g,k}$ |
| 混合扰动 | 多项同时变化 |

每类都要保存 Full 真值和投影后的 Lite 等效标签。

## 五、频率步进建议

V1.6-Lite 已经使用 $L_{\max}\approx v_p/(2\Delta f)$ 和 $\Delta z\approx v_p/(2B)$，并要求记录 $step\_hz$。这部分必须严格执行。

### 5.1 频率步进设计公式

用最低可能传播速度 $v_{\min}$ 设计：$\Delta f\leq v_{\min}/(2\gamma_L L_{\mathrm{target}})$，其中 $\gamma_L$ 是安全系数，建议取 $1.2$ 到 $1.5$。

若取 $v_{\min}=1.8\times10^8\ \mathrm{m/s}$：

| 目标长度 | 无安全系数上限 | $\gamma_L=1.2$ 后建议 |
|---:|---:|---:|
| $2.5\ \mathrm{km}$ | $36\ \mathrm{kHz}$ | $\leq30\ \mathrm{kHz}$ |
| $5\ \mathrm{km}$ | $18\ \mathrm{kHz}$ | $\leq15\ \mathrm{kHz}$ |

经过现场电缆的数据试验，**阶段二建议一共6250个点，频率范围为：9k-200MHz，step_hz=32kHz**

阶段三建议step_hz小于18kHz，点数进一步增加（还没有敲定）。



### 5.2 推荐两类频率视图

| 视图 | 频率策略 | 用途 |
|---|---|---|
| 长距离视图 | 小 $step\_hz$，中低频，线性等间隔 | IFFT、step、端点、远端候选 |
| 局部细节视图 | 高 $f_{\max}$，可更稀疏 | 近端/中段缺陷细节、论文补充评估 |

训练主模型时，先保证长距离视图正确。不要一开始追求 1 GHz 全带宽，否则会牺牲长距离 step 解释。

## 六、不同阶段训练建议

当前 V1.6-Lite 路线是阶段一 $K_{\max}=3$、阶段二 $K_{\max}=5$、阶段三 $K_{\max}=7$，阶段二默认 $M_f=2048$、$M_\tau=1024$ 到 $2048$、$d_{\mathrm{model}}=64$ 或 $128$、batch size 4 到 8。

V1.6-Lite 采用分阶段训练，因此每个阶段结束时必须保存 checkpoint、配置文件、数据版本和训练日志。不能只保存最终模型。每个 checkpoint 至少包含模型权重、优化器状态、学习率调度器状态、EMA 损失量级、损失权重、随机种子、数据生成器版本、训练数据索引和频率网格配置。

| 阶段                | 必须保存的 checkpoint                                        |
| ------------------- | ------------------------------------------------------------ |
| 生成器单元测试      | 数据生成器版本、样本可视化、耗时报告、标签派生检查报告       |
| 时延分支预训练      | `temporal_pretrain_best.pt`、`temporal_pretrain_last.pt`     |
| 阶段一 $K_{\max}=3$ | `stage1_k3_best.pt`、`stage1_k3_last.pt`                     |
| 阶段二 $K_{\max}=5$ | `stage2_k5_best_f1.pt`、`stage2_k5_best_s11.pt`、`stage2_k5_last.pt` |
| 阶段三 $K_{\max}=7$ | `stage3_k7_best.pt`、`stage3_k7_last.pt`                     |
| 真实数据微调        | `real_ft_best.pt`、`real_ft_last.pt`                         |

阶段切换时必须保留上一阶段最佳模型，而不是只接着 last checkpoint 训练。例如阶段二从阶段一初始化时，应记录初始化来源；真实数据微调时，应记录冻结哪些模块、哪些模块使用小学习率、Near/End 残差是否启用。这样后续若真实数据效果变差，可以回滚到仿真阶段最佳模型，而不是重新从头训练。

### 6.1 第 0 步：生成器单元测试

先生成 200 到 500 条样本，不训练网络，只检查 $S_{11}^{obs}(f)\rightarrow r^{obs}(\tau)\rightarrow s^{obs}(\tau)\rightarrow \hat L_{\mathrm{tot}}^{rule}$。

| 检查项 | 要求 |
|---|---|
| $step\_hz$ | 满足目标长度无混叠 |
| 末端 step | 人工可读出末端 |
| 缺陷热力图 | 与缺陷位置一致 |
| 缺陷长度标签 | 与生成段一致 |
| Lite 物理标签 | 与生成扰动一致 |
| Full 物理标签 | 可回溯 |
| Near/End 标签 | 与仿真设置一致 |
| $S_{11}$ | 无非物理爆炸 |
| IFFT 距离轴 | 与 $v_p,\Delta f$ 一致 |

这一步不合格，不要开始训练。

除检查物理正确性外，还必须评估单条样本生成耗时和并行吞吐量。V1.6-Lite 阶段二训练集规模建议达到 $50,000$ 到 $150,000$ 条，如果生成器吞吐不足，后续预训练、消融和重新采样都会受阻。

### 6.2 第 1 步：预训练时延端点分支

只训练 $\mathbf{X}_\tau\rightarrow h_D,w_D,c_D,h_{\mathrm{end}},c_{\mathrm{end}},\hat L_{\mathrm{tot}}^{NN}$。使用自动派生标签 $y_{\mathrm{end}}(\tau)$、$y_D(\tau)$、$w_D^{gt}(\tau)$ 和 $L_{\mathrm{tot}}^{gt}$。

损失为 $\mathcal{L}_{prop}=\mathcal{L}_{heat}+\beta_w\mathcal{L}_{width}+\beta_e\mathcal{L}_{end}+\beta_L\mathcal{L}_{L}^{NN}$。

| 指标 | 达标建议 |
|---|---:|
| 端点长度 MAE | 小于 $0.5\%L$ 或 $5$–$10\ \mathrm{m}$ |
| 近端/中段 anchor recall | $>95\%$ |
| 远端 anchor recall | $>85\%$ |
| 健康样本误候选数 | 单独统计，越低越好 |

这一阶段必须混入 hard negative，否则时延分支会把所有包络峰都当成缺陷候选。

### 6.3 第 2 步：阶段一最小闭环，$K_{\max}=3$

接入频域主分支、slot head 和物理层，先用 $K_{\max}=3$。

| 训练进度 | anchor 来源 |
|---|---|
| 前期 | 70% 真值派生 anchor，30% 预测 anchor |
| 中期 | 30% 真值派生 anchor，70% 预测 anchor |
| 后期 | 100% 预测 anchor |

损失可用 $\mathcal{L}_{complex}+0.1\mathcal{L}_{logamp}+\lambda_{prop}\mathcal{L}_{prop}+\lambda_{slot}\mathcal{L}_{slot}+\lambda_{prior}\mathcal{L}_{prior}$。阶段一可以暂时关闭 $\mathcal{L}_{phys}^{sim}$，先确认物理层和 slot 闭环稳定；也可以用很小权重验证物理头方向。

### 6.4 第 3 步：阶段二主训练，$K_{\max}=5$

正式启用 $K_{\max}=5$、$M_{\mathrm{seg}}=11$、$M_f=2048$、$M_\tau=1024$ 到 $2048$。

| 子阶段 | 重点 | 建议 |
|---|---|---|
| 前期 | 端点、候选、全局背景、gate | $\lambda_{prop}$ 较大，$\lambda_{phys}^{sim}$ 中等 |
| 中期 | slot 位置、长度、局部扰动、物理层 | 逐步降低真值 anchor 比例 |
| 后期 | 全频段 $S_{11}$ 一致性 | 降低 $\lambda_{prop}$ 和 $\lambda_{phys}^{sim}$，让 $\mathcal{L}_{complex}$ 主导 |

不要一开始就用 $M_f=4096$。先用 2048 跑稳，再做 4096 增强实验。

### 6.5 第 4 步：阶段三扩展，$K_{\max}=7$

阶段三用于 $5\ \mathrm{km}$、远端弱缺陷和多缺陷场景。启用 $K_{\max}=7$、$M_f=2048$ 到 $4096$、$M_\tau=2048$ 到 $4096$、$step\_hz=10$ 到 $15\ \mathrm{kHz}$。增加距离分层候选、受限 TGC 元数据和远端 SNR 分析。不要把阶段三机制提前塞进阶段二主结果，否则 Lite 会失去可控性。

### 6.6 真实数据微调

真实数据微调不使用仿真物理标签监督，即 $\lambda_{phys}^{sim}=0$。只使用已知总长度、高置信接头或缺陷位置、频域 $S_{11}$ 一致性、端点/候选伪标签和 Near/End 小范围残差正则。

| 模块 | 策略 |
|---|---|
| Conv stem | 冻结或极小学习率 |
| Mamba 底层 | 冻结或极小学习率 |
| 时延分支 | 小学习率 |
| slot head | 中等偏小学习率 |
| 全局背景头 | 小学习率 |
| Near/End 残差 | 极小学习率 + 强先验 |
| 物理层 | 无学习率，只接收参数头输出 |

## 七、推理建议

### 7.1 推理流程固定为两级

推理固定为两级。

第一级是 CPU 离线预处理。执行 $csv\rightarrow S_{11}^{obs}(f)\rightarrow F_{\mathrm{ifft\_full}}\text{重采样}\rightarrow r^{obs}(\tau)\rightarrow a^{obs}(\tau),s^{obs}(\tau),\Delta_\tau s^{obs}(\tau)$，并生成 $m_{\mathrm{near}}(\tau)$、$\bar x(\tau)$、$\hat L_{\mathrm{tot}}^{rule}$、$\tau_{\mathrm{end,step}}$、$\tau_{\mathrm{end,pk}}$，同时记录 $f_{\min},f_{\max},M,step\_hz$。

第二级是 GPU 网络与物理层推理。执行 $\mathbf{X}_\tau\rightarrow \hat L_{\mathrm{tot}}^{NN},\mathcal{P}_{anchor}$，再执行 $\mathbf{X}_f,\mathcal{P}_{anchor}\rightarrow q_k,x_k,l_k,\delta_{\alpha,k},\delta_{\varepsilon,k},\delta_L,\delta_{\alpha,G},\delta_{\varepsilon,G}$，最后通过物理层得到 $S_{11}^{pred}(f)$，并计算 $\mathcal{E}_{complex},\mathcal{E}_{logamp}$。

### 7.2 推理输出

每条样本输出三组结果。

A. 总长度结果：输出 $\hat L_{\mathrm{tot}}^{rule}$、$\hat L_{\mathrm{tot}}^{NN}$、$L_{\mathrm{tot}}=\hat L_{\mathrm{tot}}^{NN}\exp(\delta_L)$、$c_{\mathrm{end}}$、$|\hat L_{\mathrm{tot}}^{rule}-\hat L_{\mathrm{tot}}^{NN}|$ 和 $|\hat L_{\mathrm{tot}}^{NN}-L_{\mathrm{tot}}|$。如果三者差异很大，应标为低置信样本。

B. 缺陷列表结果：每个 slot 输出 $q_k$、$x_k^{start}$、$x_k^{end}=x_k^{start}+l_k$、$l_k$、$\delta_{\alpha,k}^{eff}$、$\delta_{\varepsilon,k}^{eff}$，同时输出 $x_{k,anchor}$、$c_k$、$w_k$ 和 $d_{end,k}$。最终报告中应区分高置信缺陷、可疑缺陷和忽略候选。

C. 物理一致性结果：输出 $\mathcal{E}_{complex}$、$\mathcal{E}_{logamp}$、$\mathrm{Err}_{step}$、$\mathrm{Err}_{end,pk}$、$\mathrm{ratio}_{floor}$ 和 $\mathrm{ratio}_{sat}$。如果 $S_{11}^{pred}$ 与 $S_{11}^{obs}$ 拟合差，即使某个 $q_k$ 很高，也不能给出强诊断结论。

### 7.3 缺陷判定用验证集校准

不要直接使用 $q_k>0.5$ 作为缺陷判定。$q_k$ 是网络输出，不天然等于真实概率。

建议在验证集上校准两个阈值：$\theta_{high}$ 用于高置信自动报告，precision 优先；$\theta_{low}$ 用于可疑缺陷提示，recall 优先。阈值扫描应按近端、中段、远端分别统计，因为远端弱反射下 $q_k$ 分布可能不同。

论文中可以报告 F1 最优阈值；工程诊断中应报告高置信阈值下的 precision 和低阈值下的 recall。对于真实数据，如果没有完整缺陷真值，至少要用已知拼接点、人工高置信案例和健康长电缆样本做阈值 sanity check。

### 7.4 重叠缺陷合并

如果两个预测缺陷距离很近或区间高度重叠，不应直接报告两个缺陷。可采用后处理规则：若 $|x_i-x_j|<r_{merge}$，或 $[x_i^{start},x_i^{end}]$ 与 $[x_j^{start},x_j^{end}]$ 高度重叠，则合并为一个区间，$x_{merge}^{start}=\min(x_i^{start},x_j^{start})$，$x_{merge}^{end}=\max(x_i^{end},x_j^{end})$，$q_{merge}=\max(q_i,q_j)$。

不建议默认使用 $q_{merge}=1-(1-q_i)(1-q_j)$，这个公式偏乐观，工程报告里容易放大置信度。

## 八、数据规模建议

如果生成成本可接受，阶段二主结果建议：

| 数据集 | 数量建议 |
|---|---:|
| 训练集 | $20,000$ 到 $40,000$ 条 |
| 验证集 | $3,000$ 到 $5,000$ 条 |
| 测试集 | $2,000$ 到 $4,000$ 条 |
| hard negative 专项测试 | $500$ 到 $1,000$ 条 |
| 远端弱缺陷专项测试 | $30$ 到 $70$ 条 |
| 健康长电缆专项测试 | $20$ 到 $50$ 条 |

如果高保真仿真成本高，可以先用低/中保真生成器做大规模预训练，再用高保真样本微调和验证。真实数据不建议从头训练，主要用于阈值校准、domain gap 检查、Near/End 微调和论文案例展示。

## 九、最终检查清单

| 编号 | 必须检查项 |
|---:|---|
| 1 | 保存 $f,\operatorname{Re}(S_{11}),\operatorname{Im}(S_{11})$ |
| 2 | 保存 $f_{\min},f_{\max},M,step\_hz$ |
| 3 | 保存完整电缆规格先验 $\mathbf{m}$ |
| 4 | 保存总长度 $L_{tot}^{gt}$ |
| 5 | 保存缺陷列表 $\{x_u^{start},l_u\}_{u=1}^{N_D}$ |
| 6 | 健康样本明确写 `defects: []` |
| 7 | 保存 Lite 全局扰动 $\delta_{\alpha,G}^{gt},\delta_{\varepsilon,G}^{gt}$ |
| 8 | 保存 Lite 局部扰动 $\delta_{\alpha,k}^{gt,eff},\delta_{\varepsilon,k}^{gt,eff}$ |
| 9 | 保存 Full 扰动 $\delta_g,\delta_\sigma,\delta_{\tan\delta}$ |
| 10 | 保存 Near/End 校准值和残差 |
| 11 | 保存噪声、SNR、case id、随机种子、生成器版本 |
| 12 | 派生端点热力图、缺陷热力图、候选宽度和 slot 匹配标签的程序必须版本化 |

最终原则是：**V1.6-Lite 的数据生成不能只保存最小标签。总长度和缺陷列表是主强监督，Lite 物理扰动是仿真辅助监督，Full 扰动和 Near/End 残差是必须保存的扩展真值。训练时可以分层使用，但生成器一开始就必须完整记录。**
