有两个关键现象必须重视。

第一，**2 km 以下案例对 30~40 kHz 都比较宽容**。比如 250 m、300 m、543 m、780 m、830 m、1000 m、1500/1600 m，这些案例中，远端或主反射峰在 30、35、40 kHz 下位置基本稳定。对这些长度，40 kHz/200 MHz 的高分辨率方案确实可用。

第二，**2.4 km 案例是决定参数上限的关键样本**。在某地-2400m 中，随着 `step_hz` 从 30 kHz 增加到 40 kHz，远端相关响应越来越靠近 IFFT 距离窗口末端。40 kHz 的理论窗口只有约 2.51 km，已经几乎贴着 2.4~2.5 km 的上限运行。此时边界伪影、周期连接效应、末端强反射拖尾都会和真实远端反射混在一起，不适合作为统一测试标准。

## 3. 对 30~40 kHz 的分档判断

### 40 kHz / 200 MHz / 5000 点

这个方案分辨率最高，但对 2.5 km 是卡边界：

```text
Dmax ≈ 2.51 km
```

它对短电缆没问题，但对 2.4~2.5 km 电缆几乎没有余量。某地-2400m 的结果已经显示出明显窗口边界风险。因此我不建议把它作为 **≤2.5 km 通用参数**。

结论：

```text
40 kHz 不适合作为 2.5 km 以下统一标准。
只适合明确长度 <1.5~2.0 km 的高分辨率测试。
```

------

### 37.5 kHz / 187.5 MHz / 5000 点

这个方案比 40 kHz 稍好，但距离窗口也只有约：

```text
Dmax ≈ 2.68 km
```

对 2.4~2.5 km 仍然偏紧。某地-2400m 中，远端区仍明显受窗口末端影响。它可以作为短电缆或中等长度电缆的高分辨率方案，但不适合作为 2.5 km 标准。

结论：

```text
37.5 kHz 仍偏激进，不建议作为通用标准。
```

------

### 35 kHz / 175 MHz / 5000 点

这个方案的距离窗口约：

```text
Dmax ≈ 2.87 km
```

它比 37.5/40 kHz 好很多。对 2 km 以内案例，表现稳定；对 2.4 km 案例，已经能覆盖，但余量仍然不大。

结论：

```text
35 kHz 可以作为高分辨率激进方案。
但如果你要保证覆盖 2.4~2.5 km，不建议把 35 kHz 作为唯一主标准。
```

------

### 32.5 kHz / 162.5 MHz / 5000 点

这个方案的距离窗口约：

```text
Dmax ≈ 3.09 km
```

对 2.5 km 的余量约 1.24 倍。它比 35 kHz 稳，比 30 kHz 分辨率略高。若 VNA 支持 32.5 kHz 这种非整数十进制步进，它是一个很好的折中方案。

结论：

```text
32.5 kHz 是高分辨率优先下的折中推荐。
```

------

### 30 kHz / 150 MHz / 5000 点

这个方案的距离窗口约：

```text
Dmax ≈ 3.35 km
```

在 30~40 kHz 范围内，它是对 2.5 km 最稳的方案。虽然分辨率不如 40 kHz/200 MHz，但 150 MHz 对公里级电缆已经有较好的距离分辨能力，而且不会像 40 kHz 那样卡在距离窗口边缘。

结论：

```text
30 kHz 是我对 ≤2.5 km 电缆最推荐的高分辨率优先主方案。
```

## 4. 最终建议

如果你坚持 **高分辨率优先**，并且希望 **约 5000 个点**，我建议把主测试参数定为：

```text
start_hz = 9 kHz
step_hz = 30 kHz
stop_hz ≈ 150 MHz
points ≈ 5000
```

这是我认为最稳的高分辨率方案。它比 20 kHz / 100 MHz 分辨率更高，又不像 40 kHz / 200 MHz 那样卡边界。

如果你想进一步提高分辨率，并且 VNA 支持对应设置，可以把备选方案设为：

```text
start_hz = 9 kHz
step_hz = 32.5 kHz
stop_hz ≈ 162.5 MHz
points ≈ 5000
```

这个方案我认为仍然可以用于 2.5 km 以下，但比 30 kHz 更吃现场速度因子、长度误差和末端反射质量。

如果你明确知道电缆不超过 2 km，可以使用：

```text
start_hz = 9 kHz
step_hz = 35 kHz
stop_hz ≈ 175 MHz
points ≈ 5000
```

如果你要覆盖 2.4~2.5 km，我不建议使用 35 kHz 以上作为主方案。

------

## 5. 我不推荐的参数

不建议把下面两个作为 2.5 km 以下统一现场测试标准：

```text
step_hz = 37.5 kHz, stop_hz ≈ 187.5 MHz
step_hz = 40 kHz, stop_hz ≈ 200 MHz
```

尤其是：

```text
step_hz = 40 kHz, stop_hz ≈ 200 MHz
```

它看起来分辨率很高，但对 2.5 km 的距离窗口几乎没有余量。某地-2400m 的现场数据已经说明，远端区会贴近 IFFT 周期边界，容易和边界伪峰、周期混叠、末端拖尾混在一起。

```text
9 kHz ~ 162.5 MHz
step_hz = 32.5 kHz

```

