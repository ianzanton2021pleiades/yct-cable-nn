# CST_Reproduction V1：细分梯形单元与频变损耗对照

## Summary

- 保持 V0 冻结，不修改 CST 工程、REF 算法或现场原始数据。
- V1 只改进现有 CST 复现程序，不建立 Field/YJV 模型。
- V1 默认模型为 `0.1 m` 细分梯形网络。
- 同一程序增加固定 RLGC、连续 RLGC、DG V3 风格频变损耗三类对照。
- 现场数据只用于验证“145 MHz 共性截止”和缺陷后波动，不参与 V1 参数建模。

正式单元尺寸矩阵为 `0.4/0.2/0.1/0.05 m`。0.8 m 不进入正式验收，因为不能整除10 m段长，会同时改变接头位置。

已知实验趋势：

| 单元尺寸 | 近似截止频率 | 算法1接头后尾波/主峰 | 算法2接头后尾波/主峰 |
| -------- | -----------: | -------------------: | -------------------: |
| 0.4 m    |      145 MHz |                0.159 |                0.121 |
| 0.2 m    |      291 MHz |               0.0196 |                0.094 |
| 0.1 m    |      581 MHz |              0.00362 |               0.0363 |
| 0.05 m   |     1162 MHz |              0.00398 |               0.0223 |

这支持“0.4 m 单元过宽泛”是重要原因，但接头参数和损耗仍作为独立因素保留。

## Implementation Changes

### 1. Circuit model

在 [V1/cst_fdr_reproduction.py](D:/GitRepository/Cable-NN/DifferentAgent/CodeX/CST_Reproduction/V1/cst_fdr_reproduction.py) 中增加模型变体：

- `fixed_ladder_0p4m`
- `fixed_ladder_0p2m`
- `fixed_ladder_0p1m`（默认）
- `fixed_ladder_0p05m`
- `fixed_continuous`
- `dg_loss_0p1m`

固定 RLGC 细分时，按单位长度等比例缩放：

```text
scale = cell_length / 0.4
Rcell = 0.01 * scale
Lcell = 0.3 μH * scale
Gcell = (1/200 kΩ) * scale
Ccell = 16 pF * scale
```

所有模型保持：

- 50 Ω端口参考；
- TL1：1 m、135 Ω；
- TL3/TL4：0.5 m、300 Ω；
- 特殊接头：0.1 Ω、1 μH、8 pF、200 kΩ；
- 10/20/30 m接头位置；
- 末端开路；
- 总电缆主体40 m。

15 m缺陷保持 V0 的原始物理范围 `14.8–15.2 m`：

- 0.2 m网格：2个单元；
- 0.1 m网格：4个单元；
- 0.05 m网格：8个单元。

### 2. Continuous RLGC reference

`fixed_continuous` 使用固定 V0 单位长度参数，通过：

```text
γ = sqrt((R' + jωL')(G' + jωC'))
Zc = sqrt((R' + jωL')/(G' + jωC'))
ABCD = [cosh(γl), Zc sinh(γl);
        sinh(γl)/Zc, cosh(γl)]
```

该模型只用于消除离散单元截止，不能标记为严格 CST 电路复现。



### 3. FDR and output contract

两套算法保持当前 REF 参数完全不变：

- 算法1：复数 S11、自动 DC、共轭双边谱、Hann、`εr=2.23`；
- 算法2：95 m、VF=0.6715、5/50点平滑、10000时间点、10 V、归一化系数6.5、50 Ω、跳过首点、只用实部。

S11 不按算法拆分，统一保存三列：

```text
Frequency_Hz,S11_Real,S11_Imag
```

输出内容：

- 默认0.1 m模型的9个工况；
- 连续 RLGC 模型的9个工况；
- 0.4/0.2/0.1/0.05 m基准模型的分辨率收敛CSV；
- 算法1/算法2距离域CSV；
- 指标CSV、JSON和Markdown报告。

## Test and Acceptance Plan

- 拓扑检查：0.4/0.2/0.1/0.05 m均保持40 m主体、10/20/30 m接头和14.8–15.2 m缺陷范围。
- 参数守恒：细分后总 R/L/G/C 与 V0单位长度等效值一致。
- 收敛检查：0.1 m与0.05 m的S11及距离域结果接近连续模型。
- 基准震荡检查：0.1 m固定模型的接头后尾波/主峰比目标不高于约0.05。
- 截止检查：0.1 m模型的离散截止频率高于200 MHz，且不再出现V0在145 MHz附近的幅相断崖。
- REF一致性：算法2与REF核心结果误差保持在数值精度范围内。
- 输出检查：所有S11、FDR数组有限、长度一致，CSV表头和列数正确。
- 现场参照检查：常州220 kV及其他现场文件不应被强行解释为统一145 MHz截止。
- 缺陷局部性检查：现场RG58的两套算法应继续在约49.2 m定位局部峰，缺陷后区不得出现同量级独立峰。
- 不运行CST本体，不声称与CST逐点一致；若以后取得CST ASCII S11，再增加数值对比。

## Locked Assumptions

- V1默认使用0.1 m细分梯形模型。
- 15 m缺陷保持原0.4 m物理范围。
- 50 Ω端口失配保留，不人为匹配掉。
- 135 Ω/300 Ω TL和特殊接头先保留，在消融实验中单独评估。
- 传播速度标定继续使用当前两套FDR参数；速度差只作为位置标尺问题记录。
- 现场数据只作外部验证，不作为V1的Field模型或YJV通用参数。
- 所有修改仅发生在 `DifferentAgent\CodeX\CST_Reproduction\V1`，V0保持不变。
