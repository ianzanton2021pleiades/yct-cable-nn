# Core-16 现场版：现场证据与实现说明

日期：2026-10-22；主导：CodeX；资料盘点、代码实现及定量计算由 GPT-6 Luna Max 分工完成。

## 结论与版本定位

本轮建立独立的 `DifferentAgent/CodeX/Core16_Field`，保留两个响应算法、C00–C15 的16类机制和全部三条物理路线，开路作为主对照。原 Core-16、REF、DG V3、GUI 及现场源文件不修改。

这是**现场统计约束的探索版本**，还不是冻结的深度学习数据生成参数。近端模型已有短接和现场复数 S11 的联合拟合依据；体材料损耗、接头 RLC、局部缺陷宽度及轻微分布不均匀仍含先验。不能将16类机制逐一宣称为现场确诊，也不能将一条曲线的非唯一拟合称为真实 RLGC 反演。

## 2. 可支持的现场规律

### 2.1 总S11幅值不是远端衰减曲线

下表仅对有短线范围佐证的样本：先在各顶层案例内取曲线频带中位数，再让60个案例等权统计。每段频带可用案例数见JSON，不将高频末端可见性等同于总反射幅值。

| 频带 | 案例等权q05 / q50 / q95，线性`|Γ|` |
|---|---|
| 9–100 kHz | 0.348 / 0.689 / 0.917 |
| 0.1–1 MHz | 0.281 / 0.501 / 0.671 |
| 1–5 MHz | 0.415 / 0.552 / 0.617 |
| 5–10 MHz | 0.586 / 0.722 / 0.777 |
| 10–50 MHz | 0.746 / 0.820 / 0.835 |
| 50–100 MHz | 0.710 / 0.772 / 0.812 |
| 100–200 MHz | 0.517 / 0.672 / 0.724 |
| 0.2–1 GHz | 0.307 / 0.367 / 0.448 |

大量电缆的总反射在10–50MHz反而较大，不能对其简单套用“越高频、幅值越低”的整曲线损耗拟合。短接与测量共有明显近端相位/幅值结构，需把夹具及近端效应与传播后的接头、末端分开。短线中2条曲线有`|Γ|>1.01`；全库22条、最大约1.0194，不能把实测轻微超界直接当电缆有源。

### 2.2 同一受控异常随距离衰减、展宽并出现峰位偏移

1500m单接头浸水试验有正常参照和11个浸水位置，实际位置为100、200、300、400、500、600、700、900、1100、1300、1400m。不存在必须补齐800/1000/1200m的要求。

对厂商已存脉冲作“浸水−正常”差分，统一3m滑动均值；9个位置满足峰值至少为邻域残差RMS三倍的操作性可辨标准。它不是统计显著性检验：

- 有效差分峰衰减约40.45dB/km，R²=0.9285，n=9。
- 可辨差分负峰半高宽约从100m处3.05m增至1100m处75.58m；拟合趋势约76.85m/km，R²=0.9915。
- 峰位相对位置标签存在偏移，例如100m约+3.37m、1100m约+55.09m。没有据此改写现场位置标签。
- 1300m位置的峰/残差比约1.87，不入拟合；1400m靠近搜索边界且半高宽不闭合，单列。

该试验TXT明确说材料损耗远大于普通XLPE。因此40.45dB/km是这个试验的**差分峰**趋势，不是导体传播常数，不直接写进通用XLPE参数。厂商`vendor_*`响应也没有被冒称为本项目Algorithm 1/2。

### 2.3 接头、拓扑与佐证要分层

637m案例有人工接头53/183/332/412/514m，低压脉冲和工程师圈定的阻抗下降区间提供另一层旁证；412m疑似两个头，不虚构其精确间距。960m分段则记录了芯-地测量、屏蔽接地疑问，不能直接当标准芯-屏蔽材料反演。

超范围的新疆箱变案例只作终端影响旁证。莱芜报告有解体/换头后绝缘恢复的证据，但存在位置口径差异且本目录无FDR。无锡报告有绝缘/局放对照，但报告内也有线路编号及绝缘值前后不一致。波形判断、现场人员推测和解体结论不能混成同等级精确标签。

## 3. 近端等效拟合及其限度

用5–200MHz、512个对数等距点，以“近端延时线+串联RL/并联GC+半无限等效电缆输入”同时拟合短接与测量复数S11；两组残差等权。单短接不能唯一求三项校准误差，短路时该拓扑的并联C也不可独立识别。没有执行`−Γ测量/Γ校正`。

| 代表案例 | 测量单独拟合RMSE | 联合后测量RMSE | 联合后短接RMSE |
|---|---:|---:|---:|
| 无锡蓝安，文件名1100m | 0.1380 | 0.1403 | 0.1466 |
| 7月20日637m A相 | 0.1150 | 0.1703 | 0.2951 |
| 9月14日2430m A相 | 0.0803 | 0.0887 | 0.0805 |

当前配置选第三例作为代表性候选：等效负载约19.8Ω，近端串联R约7.9Ω、L约1.15μH、单程延时约24.4ns、1MHz单程损耗约0.154dB；并联C贴近零边界。**这些不是实物夹具元件测量值**。另两例拟合不足说明一个固定简单前端不能代表全库；不能将三例系数粗暴平均后称通用标定完成。

随后针对同一2430m案例，在9kHz–20MHz共同网格上拟合固定末端窗内完整A1脉冲向量，并弱约束复数S11；只调有效趋肤项、介损项和材料传播速度，不移动距离轴或末端。得到Rskin约0.06464Ω/m@1MHz、有效tanδ约0.031676、材料速度约179.325m/μs；响应距离换算仍固定172m/μs。

A1末端窗RMSE由1.100×10⁻³降至9.555×10⁻⁵，峰幅比由4.455降至0.932；A2峰幅比由3.669降至0.878，复数S11 RMSE由0.08286降至0.07924。但模型峰位仍晚于实测：A1约107.5m、A2约73.0m。当前配置采用这个整体窗形态误差更低的候选，**不把峰位问题视为解决**。这些系数吸收了接头和材料等未辨识因素，不是健康XLPE的实测介损，也不能凭FDR标注长度唯一反演真实波速。此比较与近端拟合共用同一A相，属于拟合内证据，尚无独立泛化验证。

## 4. 现场版Core-16的实现

### 保留与改变

保留C00正常、C01/C02局部R增加、C03/C04/C05不同空间形式的G增加、C06/C07/C08的C变化、C09–C12复合变化、C13–C15整段异型替换。原YAML继续提供类型名和扰动方向，避免重新定义16类。

默认长度600/1500/2400m。长区段随长度缩放，局部异常宽度单独设为2m；局部接触电阻按原案例总欧姆增量保留，不随区段展宽重复增加。2m及严重度仍是探索先验，不能说是从未标注FDR识别出来的缺陷尺寸。

接头相对位置参考637m案例的5个非均匀位置；强度目前使用统一的RLC先验，距离衰减由传播计算产生。主体加入同seed的小幅分布不均匀，全部16类共用相同背景及接头，便于看出机制变化。

三路线全部默认计算：频变连续RLGC、1MHz冻结的连续RLGC、1MHz冻结的0.1m梯形。固定路线用于对照其频变建模缺失，不能预设三路都能同样拟合现场全频带。旧版100MHz锚定结果未改。

频变核采用直流项、`(1+j)·Rskin·sqrt(f/fref)`及介质损耗，传播和复数特性阻抗来自同一套Z′/Y′；支持Debye项但默认不凭空增加已确认的弛豫参数。G/C独立扰动，C单独改变时不自动把G同步放大。

clean层不加夹具，field层加等效近端网络。两层均保留真实物理背景和接头；没有为了“看起来像现场”叠加未知强度的随机噪声，也没有用实测距离域模板、末端重构或反投影替换S11。

### 数值与响应口径

连续网络使用与ABCD等效的`tanh`归一化形式，并以负指数等价式计算，避免高损耗时复`tanh`内部溢出；梯形同质区段使用单元矩阵快速幂，避免2500m逐格乘25,000次。整体尺度归一化不改变S11。

Algorithm 1仍为复数S11、DC外推、Hann、IFFT及积分；Algorithm 2仍只用实部去均值后的余弦积分，再差分形成脉冲。两种算法幅值不直接互相等同。A1同时保留旧版`step_raw`和去除旧版dt量纲因子的带限累计`step_rho`，不把其直接叫作绝对电缆阻抗。

现场对数频点不能用最小间隔铺满1GHz。新响应接口显式控制均匀重采样网格、波速、距离范围，平滑窗按米定义。原始网格的大间隙不会因为插值而增加测量信息。

默认正式生成9kHz–200MHz、至少32768点；点数也随目标距离检查采样需求。频率带宽的近似空间分辨率为`v/(2B)`，FFT距离采样步长与之不同，Hann窗主瓣更宽。开路末端的观测峰可因频散、夹具和带限而偏离物理长度，不强行把峰搬回标签。

## 5. 文件与运行

入口：`DifferentAgent/CodeX/Core16_Field/generate_field_core16.py`；配置：`field_config.json`。源文件和整个E盘资料只读；输出在本实验`.gitignore`忽略的`output/`、`assets/`、`cache/`内；脚本、配置及说明保留。小体量人工判读的长度范围与来源元数据保存在`scope_evidence.json`，不将这些不可从波形自动恢复的判读只留在被忽略的输出里。

正式批处理由用户执行，包含三长度、16类、三路线、clean/field两层及两个响应算法，共288组case-route-layer。命令不启动GPU：

```powershell
& 'E:\Anaconda\envs\gpushare_cu124\python.exe' -X utf8 -B 'D:\GitRepository\Cable-NN\DifferentAgent\CodeX\Core16_Field\generate_field_core16.py'
```

只生成一种长度可加`--lengths 1500`；选择少量机制可加`--cases C00 C09 C14`。`--quick`限制到20MHz，4096基础频点、A2约1m步长，只用于较低带宽的案例预览，不能代替200MHz正式结果。

输出包括复数S11 CSV、两算法原始/平滑响应NPZ、几何与材料参数truth.json、指标metrics.csv、运行口径profile_summary.json，以及每长度每类型一张三路线双算法图板。进度逐组显示完成比例、耗时。
